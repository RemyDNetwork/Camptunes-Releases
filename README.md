# Camptunes downloads

Public distribution files for Camptunes. The application source is maintained in a separate private repository.

Camptunes plays the public camp recording collection directly from Google Drive. `catalog.json` contains browsing metadata only; audio files remain in Drive.

## Downloads

[View releases](https://github.com/RemyDNetwork/Camptunes-Releases/releases)

Camptunes 0.1.0 Preview 1:

- [Android APK](https://github.com/RemyDNetwork/Camptunes-Releases/releases/download/v0.1.0-preview.1/Camptunes-0.1.0-android.apk)
- [Windows installer](https://github.com/RemyDNetwork/Camptunes-Releases/releases/download/v0.1.0-preview.1/Camptunes-0.1.0-windows-setup.exe)
- [Windows portable ZIP](https://github.com/RemyDNetwork/Camptunes-Releases/releases/download/v0.1.0-preview.1/Camptunes-0.1.0-windows-x64.zip)

Downloads are public and require no GitHub account. Install over an existing Camptunes installation to keep downloads, favourites and playlists. For the portable Windows version, extract the entire ZIP before running `camptunes.exe`.

Windows installers are unsigned and may show a publisher warning. Apple installers are pending signing credentials and further iPhone testing. Unsigned iOS app bundles are not installable releases. Preview releases are separate from the stable in-app update channel.
